# CCMania++

**ITGmania that plays NotITG mod charts. Built by Cutthroat Carnivore.**

CCMania++ is ITGmania 1.3.0 plus a layer that runs NotITG modfiles: Lua mods, shaders, background layers, arrow proxies and 100+ extra NotITG mods. It ships ready to play, with the Cutthroat Carnivore theme, the Cutthroat Carnivore noteskin and the CCMania++ Top 20 charts. No separate installs.

## Download

### [Get the latest release (Mac, Apple Silicon)](https://github.com/CutthroatCarnivore/CCManiaPlusPlus/releases/latest)

Windows and Linux versions are in progress.

## Install

1. Unzip it anywhere. An external drive is fine.
2. Open `CCMania++.app`. The first time, macOS may block it: right-click the app, choose **Open**, then **Open** again.
3. Already use ITGmania on this Mac? CCMania++ copies your settings, offset, pad/keyboard mapping and profile settings from it on every launch. Your normal ITGmania is never changed, and scores you set in CCMania++ stay in CCMania++. To turn that off, put an empty file named `cc_no_import.txt` in the `Save` folder.
4. To add songs or NotITG packs, drop the pack folder into `Songs` and restart.

## NotITG packs

The download doesn't bundle anyone else's packs. Grab the NotITG packs you want from the NotITG community and drop them into `Songs`. CCMania++ is tested against Mod Jam Easy Modo, Mods Boot Camp and OISRT - Day 1.

## Status

Still a beta. Every release lists what's new and the known gaps. Not every NotITG effect matches NotITG exactly yet.

Found something off? Report it in the #ccmania++ channel on the Cutthroat Carnivore Discord. The song name and a screenshot help a ton.
